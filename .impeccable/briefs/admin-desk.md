# Admin desk

Mode: Operate

## Direction contract

THESIS: A device-bound office desk for assigning work to named people, not a SaaS card grid or a docket costume.

OWN-WORLD: Olive-metal shell, kraft work surface, Source Sans 3 at a tight scale. Colour lives in the header and in status inks. Density like labeled file tabs.

STORY: Sign in with device ID and admin password. Switch Tasks / Team. Create, edit, delete tasks; assign each to a member; add members. The database is the truth.

FIRST VIEWPORT: Coloured header with office name, device, sign out. Hanging-file tabs for Tasks and Team (signature move: active tab lifted in forest ink, others recede). Tasks: form left, list right; each row shows title, person, status. Delete sits alone.

FORM: Hanging lateral file cabinet (grounded list item 5; seed 1c9c92cf). Raises: brightest-corridor selection; member name plate + one-line role; isolated delete; rank by weight/case.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
